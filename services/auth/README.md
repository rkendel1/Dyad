# Dyad Auth Service

This is a placeholder authentication service for the Dyad development stack.

## Purpose

Provides authentication and authorization endpoints for Dyad applications.

## Endpoints

- `GET /health` - Health check
- `POST /auth/register` - User registration
- `POST /auth/login` - User login
- `POST /auth/logout` - User logout
- `GET /auth/verify` - Token verification

## Development

The service is automatically started with the Docker Compose stack on port 4000.

## Implementation

This is a basic placeholder. Implement your authentication logic as needed for your specific requirements.
